# 하이오피 (경남 지역 오피)

경남 지역별 오피 생활권 가이드. 울산오피부터 공개하며, 최신 목록은 밤의달인(bamdalin.com)으로 연결합니다.

- Public site URL: https://noranghiop.com
- First region: `/ulsan`
- Stack: Next.js 16, React 19, Tailwind CSS 4

## Commands

```bash
npm install
npm run dev
npm run build
```

## Regions

지역 데이터는 `src/lib/regions.ts`가 단일 소스입니다. 경남 지역을 추가할 때 여기에 넣고 `/[slug]`·네비·sitemap이 자동 반영됩니다.
